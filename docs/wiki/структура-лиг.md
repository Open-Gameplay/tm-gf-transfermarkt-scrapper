# Структура лиг по странам

Как Transfermarkt представляет футбольные лиги разных стран. Особенности,
которые влияют на парсинг, dedup и career mode.

## Модель данных (v2)

```
data/
├── clubs.json              # Уникальные клубы по club ID
├── leagues.json            # Метаданные лиг (без клубов)
├── tournament_structure.json  # Связи между лигами
└── leagues.html            # Вьювер для просмотра
```

### clubs.json — уникальные клубы

```json
{
  "221": {
    "id": "221",
    "name": "Santos FC",
    "leagues": ["BRA1", "BCP1"]
  }
}
```

Каждый клуб — одна запись. Поле `leagues` показывает в каких лигах числится.

### leagues.json — метаданные лиг

```json
{
  "meta": {...},
  "leagues": {
    "GB1": {
      "id": "GB1",
      "name": "Premier League",
      "country": "England",
      "clubs_count": 20,
      "players": 567,
      "totalMarketValue": 13250000000,
      "continent": "UEFA"
    }
  }
}
```

Только метаданные. Без club lists.

### tournament_structure.json — связи между лигами

Определяет пирамиду для career mode.

## Groups vs Parallel — ключевое различие

### Groups (группы)

**Одна лига**, разделённая на географические подгруппы. Все группы играют по **одним правилам**, в **одном сезоне**, с **общим pool'ом для promotion/relegation**.

**Как работает promotion/relegation:**

```
Тир 2:  ES2 (LaLiga2) — 22 клуба
         ↓ 4↓              ↑ 4↑
Тир 3:  E3G1 (Primera Fed. Grupo I) — 20 клубов
        E3G2 (Primera Fed. Grupo II) — 20 клубов
```

В конце сезона:
- **4 худших** из ES2 вылетают в E3G1 и E3G2 (распределяются по географии)
- **Лучшие** из E3G1 и E3G2 поднимаются в ES2 (по 2 из каждой группы)

Клубы **не могут** переходить из E3G1 в E3G2 — это одна лига, просто географическое разделение.

**Примеры groups:**
- Spain: Primera Federación (2 группы), Segunda Federación (4 группы)
- Italy: Serie C (3 группы: A, B, C)
- Norway: PostNord-ligaen (2 группы), Norsk Tipping-Ligaen (6 групп)
- Poland: Betclic 3 Liga (4 группы)
- Portugal: Campeonato de Portugal (4 серии)
- Sweden: Ettan (2 группы: Norra, Södra)
- France: Championnat National 1 (3 группы), National 2 (3 группы)
- Estonia: U19 лиги (Meistriliiga + Esiliiga — группы одной молодёжной системы)

### Parallel (параллельные лиги)

**Разные лиги** одного уровня. **Разные правила**, **разные клубы**, **разная география**. Каждая лига имеет **свой собственный** promotion/relegation с вышестоящим/нижестоящим тирами.

**Как работает promotion/relegation:**

```
Тир 2:  BE2 (Challenger Pro League) — 15 клубов
         ↓ 2↓              ↑ 2↑            ↑ 2↑
Тир 3:  BE3A (1ste Nationale FFA) — 12 клубов    BE3V (1ste Nationale VV) — 16 клубов
        (франкоязычная)                           (нидерландоязычная)
```

В конце сезона:
- **2 худших** из BE2 вылетают — по географии клуба (французский → FFA, фламандский → VV)
- Лучшие из BE3A поднимаются в BE2
- Лучшие из BE3V поднимаются в BE2
- **Между BE3A и BE3V нет перехода**

**Примеры parallel:**
- Belgium: FFA (франкоязычные) + VV (нидерландоязычные) на tier 3
- Russia: R3D1 (Phase 1) + R3D2 (Phase 2) на tier 3
- Wales: Cymru North + Cymru South на tier 2
- New Zealand: Northern League + Central League + Southern League на tier 1
- Czech Republic: Česká liga + Moravskoslezská liga на tier 3
- Argentina: Primera B Metropolitana + Torneo Federal A на tier 3

### Сравнение

| | Groups | Parallel |
|---|---|---|
| Правила | Одинаковые | Разные |
| Клубы | Общий пул | Разные пулы |
| Promotion/relegation | Общий пул клубов | Свой пул для каждой лиги |
| Связь между лигами | Нет (одна лига) | Нет (разные лиги) |
| Пример | Spain E3G1 ↔ E3G2 | Belgium BE3A ↔ BE3V |

**Зачем это нужно:**
- **Groups** — для больших стран, где логистика дорогая. Разделение по регионам снижает транспортные расходы.
- **Parallel** — для стран с языковыми/культурными разделениями (Belgium), или когда лига слишком большая для одной (Argentina).

## Общая логика TM

- Каждый «турнир» — отдельная запись с уникальным ID (GB1, ES1, ARG1, …)
- Лиги и кубки — разные записи, хотя кубки не имеют списка клубов (`/clubs` → 404)
- Апertura/Клаусура — разные записи для одного дивизиона (одни и те же клубы)
- Молодёжные лиги (U21, U19) — отдельные записи, часто с теми же клубами
- Страна в leagues.json приходит из TM как есть (например, "Hongkong" слитно)

## Определение уровня (tier)

Извлекается из ID: первая цифра в ID = уровень лиги в пирамиде.

| Паттерн | Пример | Tier |
|---|---|---|
| `{country}{N}` | GB1, ES1, L1 | 1 (Д1) |
| `{country}{N}` | GB2, ES2, L2 | 2 (Д2) |
| `R{N}D{M}` | R3D1, R3D2 | 3 (Д3) |
| `E{N}G{M}` | E3G1, E4G3 | 3, 4 (Д3, Д4) |
| `FR{N}{X}` | FR4A, FR5E | 4, 5 (Д4, Д5) |
| Без цифры | ARGC, POPO | 99 (неизвестный) |

## Страны с особенностями

### Аргентина

**Две параллельные ветки** (metropolitan vs federal).

| ID | Название | Tier | Клубы | Примечание |
|---|---|---|---|---|
| ARG1 | Torneo Apertura | 1 | 30 | основной |
| ARG2 | Primera Nacional | 2 | 36 | общенациональная |
| ARG3 | Torneo Federal A | 3 | 37 | **parallel** — регионы |
| URL3 | Primera B Metropolitana | 3 | 22 | **parallel** — Буэнос-Айрес |

**Пирамида:**
```
Примера (ARG1) — 30 клубов
  ↓ 2↑
Nacional (ARG2) — 36 клубов
  ├── Federal A (ARG3) — 37 клубов, регионы (parallel)
  └── Primera B Metro (URL3) — 22 клуба, столица (parallel)
```

ARG3 и URL3 — **parallel** (разные лиги, разные клубы, разные правила). Не группы.

## Dedup (устарело, v1)

В модели v2 dedup не нужен — клубы хранятся уникально по club ID в `clubs.json`.

Старый подход (v1): dedup по fingerprint (sorted club IDs) в `fetch_clubs.py --dedup`.
Удалено: 15 дублей (Apertura/Clausura пары).
