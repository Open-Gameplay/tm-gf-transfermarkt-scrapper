# Данные

## Что это

Форматы данных конвейера: **канон-JSON на TM-id** — единый источник истины (вики GameplayFootball:
[[данные-из-transfermarkt]]). Выход `build_canon.py` → `data/canon/`, валидируется
`canon_schema.json`. Ключ всех сущностей — строковый TM-id.

## Канон (`data/canon/`)

| Файл | Записи | Что |
|---|---|---|
| `meta.json` | 1 | version, snapshot_date, tm_season, counts |
| `competitions.json` | лиги | id, name, type, country{id,name}, tier, logo |
| `clubs.json` | клубы | id, name, colors[] (HEX), stadium{name,seats}, league_id, logo, founded_on |
| `national_teams.json` | сборные | id, name, coach_id, flag, emblem |
| `players.json` | игроки | id, name, first_name, last_name, birth_date, height, foot, citizenship[], position{main,other}, club_id, national_team_id, shirt_number, market_value, max_market_value, outfitter, is_retired |
| `players_market_value.json` | история | id, history[{age, date, clubId, clubName, marketValue}] |
| `coaches.json` | тренеры | id, name, citizenship, current_club_id |

### Источники полей

| Поле | Источник |
|---|---|
| позиция, рост, фут, дата рождения, гражданство, стоимость | `clubs/{id}/players` (состав клуба) |
| `national_team_id`, `shirt_number` | `national-teams/{id}/players` (только здесь) |
| `coach_id` | прямой парсинг `/mitarbeiter/verein/{id}` (API не отдаёт) |
| colors, стадион, лига, основан | `clubs/{id}/profile` |
| `outfitter`, мульти-позиции | `players/{id}/profile` (точечно) |
| `max_market_value` | `players/{id}/market_value` (история); fallback — ceapi TM |

Поля `weight` и `flag` канон не несёт: в TM их нет (эвристика конвертера) / API не отдаёт.

## Промежуточные/исторические форматы (main, не используются новым конвейером)

`tm_players_urls.json`, `tm_players_profiles.json`, `tm_players_market_values.json` и
`prepared_tm_*.json` — выход старого конвейера `tm_1…tm_999` для football_collection; новый
конвейер пишет только канон, `prepared_*` собирает конвертер.

## Ловушки

- `market_value` из API — уже число (валидаторы `parse_str_to_int`); строка «€30.00m» бывает только
  в сырых HTML.
- `max_market_value` — максимум по истории; при `null` в истории игнорируется (без TypeError).
- Роль/позиция — TM-перечисление (13 значений), не GF-роли; маппинг делает конвертер.
- `shirt_number` в каноне — строка (приводится в build_canon).
