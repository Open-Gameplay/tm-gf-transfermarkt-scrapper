# Данные

## Что это

Форматы JSON на входе и выходе конвейера. Единый канон-JSON на TM-id, к которому идём, — вики
GameplayFootball: [[данные-из-transfermarkt]].

## tm_players_urls.json (1254 записи)

```json
{ "id": "463600", "name": "Lucas Chevalier",
  "url": "https://www.transfermarkt.com/lucas-chevalier/profil/spieler/463600",
  "photo_url": "https://img.a.transfermarkt.technology/portrait/medium/463600-....jpg?lm=1",
  "number": "23", "team_id": "3377", "team_name": "France" }
```

## tm_players_profiles.json (после tm_999 — плоский)

```json
{ "id": "463600", "name": "Lucas Chevalier", "height": 189,
  "citizenship": ["France"], "isRetired": false,
  "position": {"main": "Goalkeeper", "other": []}, "foot": "right",
  "marketValue": 30000000, "outfitter": "adidas", "team_shirt_number": "23",
  "club_id": "583", "club_name": "PSG", "team_id": "3377", "team_name": "France" }
```

До tm_999 — сырые профили от API: вложенный `profile` (fullName, imageUrl, placeOfBirth, club,
agent, socialMedia…), а `maxMarketValue` подмешивает `tm_998`/`tm_999`.

## Финальные prepared_*.json

Попадают в assets football_collection (см. её [[данные]]): `prepared_tm_players_profiles.json`,
`prepared_tm_players_market_values.json`, `prepared_tm_teams.json`,
`prepared_tm_coaches_profiles.json`, `prepared_tm_legends_profiles.json`, `prepared_tm_clubs.json`,
`prepared_tm_teams_emblems.json`.

## Ловушки

- `marketValue` из API — строки вида «€30.00m»; после API-валидаторов уже числа.
- `maxMarketValue` считается максимумом по истории; при `null` в истории — `TypeError`.
- Роль/позиция в профиле — TM-перечисление (13 значений), не GF-роли; маппинг делает конвертер.
