# Промпт: расширение discover лиг через API поиск

## Контекст

Репозиторий: `C:\Users\Egor\Desktop\projects\transfermarkt_scrapper` (ветка `scraper-v2`)
API: `C:\Users\Egor\Desktop\projects\transfermarkt-api` (ветка `main`, порт 8001)

Текущий `fetch_leagues.py` берёт лиги только из национального индекса TM (`/wettbewerbe/national/`) — там **114 лиг** (только топ-лиги по странам). Но на TM доступно **намного больше** суб-лиг.

## Проблема

Пример: Россия — в индексе только RU1, RU2. Но через API поиск доступны ещё R3D1, R3D2, RUP, RUSS, R3P2, 2DVB, RJL2 (всего 9). Аналогично другие страны.

## Что нужно сделать

### 1. Изменить `fetch_leagues.py`

Заменить парсинг национального индекса на **API поиск по каждой стране**:

```python
# БЫЛО (текущий код):
resp = client.get_html("https://www.transfermarkt.com/wettbewerbe/national/")
# парсинг href → /wettbewerb/{id}

# СТАЛО (новый подход):
# Для каждой страны искать лиги через /competitions/search/{country_code}
# Country codes: RU, GB, ES, DE, IT, FR, BR, AR, PT, NL, BE, TR, UA, GR, DK, NO, SE, CH, AT, CZ, PL, RO, HR, RS, BG, HU, SK, SI, CL, CO, MX, US, JP, KR, CN, IN, AU, SA, AE, EG, MA, TN, NG, ZA, DZ, GH, CM, SN, CI и др.
```

### 2. Логика поиска

- Перебрать **~100+ country codes** (ISO 3166-1 alpha-2)
- Для каждого: `GET /competitions/search/{code}`
- Собрать уникальные ID лиг
- Проверить которые реально работают через `GET /competitions/{id}/clubs`
- Сохранить рабочие в кэш

### 3. Фильтрация

- Пропускать кубки/международные турниры (CL, EL, ECL, Copa Libertadores и т.п.)
- Оставлять только **национальные лиги** ( Type: "Liga", "1. Division", "2. Division" и т.п.)
- Можно определить по названию или по наличию клубов в ответе

### 4. Тестирование

- Сначала проверить на 5-10 странах
- Потом запустить полный поиск
- Сравнить количество лиг с текущими 114

### 5. Обновить `pilot_crawl.py`

- Шаг 1 будет использовать новый `fetch_leagues.py` с API поиском
- Остальные шаги без изменений

## Ожидаемый результат

- Вместо 114 лиг должно быть **200-300+** лиг
- Все доступные суб-лиги будут скачаны
- Количество клубов вырастет с ~1598 до ~3000-5000

## Ограничения

- API поиск может возвращать дубли (одна лига под разными кодами)
- Некоторые лиги могут быть историческими/закрытыми
- Rate limit API: не больше 2-3 запросов в секунду
- Кэш SQLite resume — можно прерывать и продолжать
